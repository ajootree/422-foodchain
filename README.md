# 먹이사슬 식당

초등 4학년 과학 먹이사슬을 배우는 태블릿용 머지·서빙 게임입니다.

[게임 시작](https://ajootree.github.io/food-chain-diner/)

동일한 먹이 카드를 합치고 알맞은 생물 손님에게 서빙합니다. 6개의 먹이사슬, 단계별 꾸미기, 집중 튜토리얼과 기기 내 영업 기록 저장을 지원합니다.

별도 설치나 빌드 없이 index.html을 열어 실행할 수 있습니다. GitHub Pages는 main 브랜치 루트에서 배포합니다.

머지는 게임 규칙이며 실제 생물이 다른 생물로 변하는 과정이 아닙니다.
